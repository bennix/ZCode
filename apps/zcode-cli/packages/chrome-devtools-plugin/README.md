# Chrome DevTools

ZenCode 内置官方 Chrome DevTools MCP 1.13.0。插件市场中启用后使用；需要安装 Google Chrome。默认使用隔离浏览器，关闭使用统计与 CrUX 查询。

CLI: `node <plugin-root>/scripts/cli.mjs --help`。性能 trace、Lighthouse、网络与内存分析按官方技能指引使用；产物保存到工作目录。远程工作区使用远端 Chrome。

Source: https://github.com/ChromeDevTools/chrome-devtools-mcp ，Apache-2.0；skills 原文随包保留。
