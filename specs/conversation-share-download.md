# 会话分享页下载入口

## 产品规则

- 用户从可导入的分享页尝试“在 ZenCode 中继续”后，若本机没有处理 `zcode:` 链接的应用，页面显示“下载 ZenCode”帮助链接。
- 下载链接指向 ZenCode 的 GitHub Latest Release 页面，由该页面根据系统和架构让用户选择安装包；它不能指向仍提供旧版 ZCode 3.14.5 的 `zcode.z.ai` 首页，也不在客户端硬编码某个发布版本。
- 分享页的中英标签、深链、预览权限和只读时间线行为保持原有规则。
- 分享失效页的“返回首页”仍指向产品站点；它与安装帮助链接是两个不同动作。

## 所有者与接口

- `ConversationShareLandingPage` 是帮助横幅是否显示的唯一状态所有者；下载地址是该页面的固定产品链接，没有服务端写入、缓存或额外状态。
- 外部 GitHub Release 页面是安装资产的权威入口。Web 分享页只生成普通 HTTPS 链接，不自行选择平台安装包。

## 验收

1. 中文和英文可导入分享页尝试打开深链后，帮助横幅的下载链接都指向公开 Latest Release。
2. 下载链接可公开访问，并指向包含当前版本安装包的 Release；不再把用户送到旧版 Landing Page。
3. 只读分享页不因下载链接调整出现新的帮助横幅。
