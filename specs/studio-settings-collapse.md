# 创作设置展开与收起

- 生图、生视频、PPT 的高级生成设置默认收起，可用标题栏按钮展开和重新收起。
- 收起只隐藏模型、推理档位、比例与时长；模式、提示词、附件、生成结果、实时进展、停止和保存操作保持可见。
- StudioSettingsDisclosure 是唯一展开状态所有者；该状态仅为组件局部 UI 状态，不进入任务、Host 或服务状态。点击按钮 → 切换局部状态 → 设置区隐藏/显示。
- 高级参数保持挂载，收起不清空输入、附件、模型选择，也不中断生成；重新进入面板默认收起。
- 按钮支持键盘 Enter/Space，提供 aria-expanded 与 aria-controls，桌面和移动端共用。
- 验收：初始输入区可见、高级参数隐藏 → 展开填写参数 → 收起确认结果仍可见 → 键盘展开确认参数保留；生成过程中同样可切换。
- 不修改生成请求、导出或持久化接口。

## 引导式首屏调整

- 创作面板首次进入时，只把模型、推理档位、比例与视频时长等高级生成参数默认收起；媒体模式、PPT 生成方式、页数、主题/提示词、参考素材及生成按钮保持可见，用户无需展开设置就能完成第一步。
- 生成/停止作为本次输入的主操作，紧随主题或提示词及补充说明；素材库、画板、结果和编辑导出操作位于主操作之后。手机 Web 引导面板内部滚动时，首次打开仍须看见完整主操作，不在页面下方另放一份重复的生成按钮。
- 展开状态仍由 `StudioSettingsDisclosure` 的组件局部状态唯一拥有。隐藏高级参数时保留挂载、选择和当前请求快照；展开/收起不能重置草稿或中断生成。重新进入面板回到默认收起。
- 验收：初始可直接填写主题或提示词，模型参数不可见；展开后可编辑模型参数；收起并再次展开后值不丢失；桌面和窄屏都能用键盘操作展开按钮。
