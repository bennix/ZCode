# Brief

## 选择

- mode：product。这是 ZenCode 的产品介绍，主角是产品本身。
- subject：ZenCode。从微信继续桌面上的同一任务，并在工作区里附上当前文件和可见 Diff。
- viewer：打开 GitHub 落地页的开发者。他们要在几秒内知道这是不是同一个工作区，以及去哪里下载。
- end state：记住名字、版本 3.14.35，和仓库地址 github.com/bennix/ZCode。
- length：22.000 秒，1920×1080，只做 16:9。落地页的介绍位就是这个画幅；9:16 要另做构图，页面用不上。
- frame rate：60。画面是界面，不是角色。
- brand：从落地页和产品图标取样。图标用 `packages` 同款 PNG，不重画。
- facts：只使用 `index.html` 里已经写明的句子。见 `facts.json`。
- assets：图标取现成 PNG；界面按真实结构用 HTML 重建。个人工作区里的文件名和任务不进画面。
- style：落地页的墨色、象牙色和黄铜，配产品里的浅灰工作台。参考原则是「一张海报先成立，再让物体把下一场带出来」，不照搬任何成片。
- sound：音乐加音效，无人声。关掉声音也要能看懂，所以不写旁白。
- autonomy：unattended。要求是把成片放上落地页，检查点写进 `ledger.md`，不在中途停下来问。
- toolchain：HTML，加上本机 Chrome 逐帧截图和 ffmpeg。仓库里没有 Remotion，界面本身就是 HTML。
- sign-off：ZenCode、3.14.35、github.com/bennix/ZCode。

音效比音乐轻。验收要求音效低于音乐；声部仍然分开，嗖声、点击和撞击各占一段频率。

## 三个方向

1. 采用。章鱼标记停在原处，工作台、手机和字围绕它换。一个会话从桌面走到微信，再落到名字上。
2. 不用。把一条 Diff 色条拉成整部片子。颜色会超出这六个颜色，也容易变成装饰。
3. 不用。命令面板把功能逐条飞出来。那是清单，没有一个动作的结果。

## 三个标志性瞬间

1. 标记飞进 ZenCode 窗口的标题栏，窗口里是同一张任务纸，进度条从左画到右。
2. 这张纸飞进手机，续接的消息落在它上方，收回的文件落在它下面，原来的任务还在。
3. 标记从任务纸上方挪到 ZenCode 左边，仓库地址留在最后。
