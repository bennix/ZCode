# 插件市场付费套餐提示展示

## 行为

- 插件市场列表卡片和插件详情标题不展示“编程套餐”付费套餐徽标。
- `listing.requiresPaidPlan` 仍是目录元数据；此展示调整不删除字段、不改变安装、启停或运行权限逻辑。
- 更新可用徽标、安装按钮及其他商店信息不受影响。

## 状态所有者与接口

- 插件目录仍拥有 `requiresPaidPlan` 元数据。
- UI 不再将该字段投影为标题徽标；不增加新的状态或接口。

## 验收场景

- 列表卡片：有或没有 `requiresPaidPlan` 时均不出现付费套餐徽标。
- 详情标题：有或没有 `requiresPaidPlan` 时均不出现付费套餐徽标。
- 插件名称、描述、更新状态和安装动作保持可见且可用。
